# 서울제일교회 주차 관리 앱

교인이 **차량을 등록**하고, 예배마다 **주차를 신청**하면, 관리자가 **승인·관리**하는 앱입니다.

- **화면**: GitHub Pages (무료, 스마트폰 웹앱)
- **데이터**: 구글 시트 (시트에서 바로 보고 고칠 수 있어요)
- **연결 다리**: 구글 Apps Script (무료, 서버 따로 필요 없음)

```
교인 휴대폰 ──▶ GitHub Pages(docs/) ──▶ Apps Script(apps-script/Code.gs) ──▶ 구글 시트
```

## 주요 기능

| 교인 | 관리자 |
|---|---|
| 휴대폰 번호 + 숫자 비밀번호로 가입·로그인 | 날짜별 신청 현황, 승인/거절/메모 |
| 차량 등록 (최대 3대, 번호 형식 자동 검사) | **차량번호 뒷자리·이름으로 검색 → 바로 전화** (차 빼 달라고 할 때) |
| 예배별 주차 신청·취소, 남은 자리 확인 | 승인 명단 **인쇄** (안내 요원용) |
| 만차면 **대기자 등록**, 자리 나면 자동 승인 | 예배·주차 대수·마감 시간 설정, 특별예배(특정 날짜) 추가 |
| 내 신청 내역과 관리자 메모 확인 | 우선배정(장애인·노약자) 지정, 비밀번호 초기화, 관리자 지정 |

## 설치 방법 (한 번만 하면 돼요, 약 15분)

### 1단계. 구글 시트 만들기
1. [sheets.new](https://sheets.new) 에서 새 시트를 만들고 이름을 `서울제일교회 주차관리`로 바꿉니다.

### 2단계. 백엔드(Apps Script) 붙이기
1. 시트 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
2. 왼쪽 `Code.gs` 내용을 모두 지우고, 이 저장소의 `apps-script/Code.gs` 내용을 붙여 넣습니다.
3. 왼쪽 ⚙️ **프로젝트 설정 → "appsscript.json 매니페스트 파일 표시"** 를 켠 뒤, `appsscript.json`에 이 저장소의 `apps-script/appsscript.json` 내용을 붙여 넣습니다. (시간대가 서울로 맞춰져요)
4. 위쪽에서 `setup` 함수를 골라 **▶ 실행**합니다. 처음에는 권한 허용 창이 떠요. (고급 → 허용)
   시트에 `교인 / 차량 / 신청 / 예배 / 설정` 탭이 생기면 성공입니다.
5. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 후 나오는 **웹 앱 URL(…/exec)** 을 복사합니다.

> ⚠️ 나중에 `Code.gs`를 고쳤다면 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** 를 해야 반영돼요. (URL은 그대로 유지됩니다)

### 3단계. 화면(GitHub Pages) 연결
1. `docs/config.js`의 `API_URL` 따옴표 안에 위에서 복사한 주소를 붙여 넣고 GitHub에 올립니다.
2. GitHub 저장소 **Settings → Pages → Branch: `main` / 폴더: `/docs` → Save**
3. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 주소가 열립니다. 이 주소를 교인들께 안내하세요.

### 4단계. 첫 가입 = 관리자
- **배포 직후 가장 먼저 목사님이 가입하세요.** 맨 처음 가입한 사람이 자동으로 관리자가 됩니다.
- 이후 [관리 → 설정]에서 **가입 코드**(예: 교회 안내 코드)를 정해 두면, 코드를 아는 교인만 가입할 수 있어요.
- [관리 → 설정 → 예배·주차 대수]에서 예배 시간과 주차 가능 대수를 실제 값으로 고치세요. (처음 들어 있는 값은 **예시**입니다)

> 스마트폰에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.

## 구글 시트 구성

시트는 앱이 자동으로 만들고 관리합니다. 직접 고쳐도 돼요. (첫 줄 제목은 바꾸지 마세요)

| 탭 | 내용 |
|---|---|
| `교인` | 이름·전화·구역·`role`(admin/member)·`priority`(TRUE=우선배정). 비밀번호는 암호화되어 저장 |
| `차량` | 교인별 차량번호·차종·색상 (`active`=FALSE면 삭제된 차량) |
| `신청` | 모든 주차 신청 기록. `status`: approved(승인) / pending(승인 대기) / waitlist(대기자) / rejected / cancelled |
| `예배` | 예배 이름·요일(0=일…6=토)·시간·주차 가능 대수·우선배정 면수·특정 날짜 |
| `설정` | 가입 코드, 자동 승인 여부, 신청 기간, 마감 시간 등 |

## 자리 배정 규칙

- **자동 승인**(기본): 주차 가능 대수가 남아 있으면 바로 승인, 다 찼으면 **대기자**.
  취소·거절·대수 증가로 자리가 나면 대기자가 **자동 승인**됩니다. (우선배정 교인이 먼저)
- **우선배정 전용 면수**: 예를 들어 30대 중 3면을 전용으로 두면, 일반 교인은 27대까지만 승인되고 나머지 3면은 우선배정 교인만 쓸 수 있어요.
- **관리자 직접 승인**으로 바꾸면 모든 신청이 `승인 대기`로 들어오고 관리자가 승인합니다.
- 신청은 예배 시작 N시간 전(기본 2시간)에 마감됩니다. 취소는 예배 시작 전까지 가능해요.

## 개인정보와 보안 안내

- **구글 시트는 공유하지 마세요.** 교인 전화번호가 들어 있어요. 앱을 쓰는 데 시트 공유는 필요 없습니다.
- GitHub에는 **코드만** 올라가고 교인 정보는 올라가지 않아요. (`API_URL`은 비밀번호가 아니며, 로그인해야만 정보를 볼 수 있어요)
- 비밀번호는 4~6자리 숫자라서 5번 틀리면 10분간 잠깁니다. 은행 수준의 보안은 아니므로, **가입 코드**를 함께 쓰시길 권해요.
- 교인 정보를 지워야 할 때는 `교인` 탭에서 해당 줄을 삭제하세요.

## 성능 참고
신청 기록이 아주 많이 쌓이면(수만 줄) 느려질 수 있어요. 앱은 최근 4,000줄만 읽도록 되어 있어 일반적인 교회 규모에서는 문제가 없고, 해가 바뀔 때 `신청` 탭의 오래된 줄을 다른 시트로 옮겨 두면 더 가벼워집니다.

## 개발자용: 테스트

```bash
npm test                 # 백엔드 규칙 테스트 15개 (구글 없이 Node에서 실행)
npm install -g playwright && npm run test:e2e   # 브라우저로 가입→신청→승인까지 따라가는 테스트
```
